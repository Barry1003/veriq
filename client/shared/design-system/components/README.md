# Shared components

Approved reusable primitives and patterns belong here, grouped by component rather than by product. Add implementations only after the corresponding Figma component is approved.

The first implemented primitive is `button.tsx`, with native button semantics and Primary, Secondary, and Ghost variants. Future examples include inputs, checkboxes, selects, badges, tooltips, tabs, data tables, search/filter controls, form fields, dialogs, and empty states.
